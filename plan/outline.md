# Module outline

1. 材料成分与研究定位：确认材料边界条件，区分低氧基线与旋锻强化增量。
2. 旋锻变形量与强度—塑性—加工硬化响应：建立宏观现象和需要解释的问题。
3. 晶粒形貌与晶界亚结构：检验连续细晶化，区分 HAGB 晶粒与 LAGB 取向域。
4. 位错储存及直接缺陷证据：建立 EBSD 代理量—XRD 总体量—TEM 直接观察的证据层级。
5. 织构、载荷路径与滑移协同：由 PF/ODF 和 FE 约束 Schmid/CRSS 分析，再由 VPSC/CPFEM 与 TEM/滑移迹线验证。
6. 强化贡献与综合机制：独立计算 Hall–Petch、Taylor 位错强化及基线项，传播不确定度并判断主导机制。

整体关系：材料边界条件 → 宏观响应 → 组织变化 → 缺陷载体 → 变形模式 → 强化归因。
