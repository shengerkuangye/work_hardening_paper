# Project overview

## Scope

建立 Gr4B23271/TA4 商业纯钛旋锻冷变形论文的模块化论证框架，并与 Xia 等关于 TA16 多道次冷轧管材的参考论文进行方法层面对照。

## Current research question

旋锻冷变形量如何改变 TA4 的拉伸响应、加工硬化能力、晶粒形貌、晶界亚结构、位错储存和织构，并且这些变化中哪些机制能够定量解释屈服强度增量及塑性损失？

## Evidence boundary

- 低氧需由本炉批 O/N/H/C/Fe 实测确认；同炉不同变形状态不能识别氧含量的因果效应。
- A、Z 为延性指标，不能据此使用“高韧”。
- IPF 不能直接证明位错增殖或滑移启动。
- 15° HAGB 晶粒尺寸未随变形量连续降低，当前不支持经典细晶强化主导。
- KAM/GROD/GOS/LAGB 为位错相关取向梯度和变形亚结构的间接证据；KAM-GND 不等于总位错密度。
- Schmid 因子只表示给定载荷下的几何有利度，实际滑移活动还需 CRSS、应力路径和直接实验验证。
- 强化贡献的主导关系必须由独立输入和不确定度计算得到，不预设“位错强化最大”。

## Reference-use principle

参考论文用于借鉴“工艺/载荷—性能—组织—变形机制—强化定量”的研究结构及验证层级，不直接迁移 TA16 冷轧管材的连续晶粒细化、孪晶衰减或滑移机制结论到 TA4 旋锻棒材。
