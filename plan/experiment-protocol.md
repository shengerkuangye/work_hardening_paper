# Experiment and evidence protocol

## Main comparison

以未变形态为基准，比较 0–48.98% 冷变形状态的拉伸、加工硬化、EBSD 和待补缺陷指标；状态效应以独立棒材重复和置信区间报告。

## Metrics

- 力学：Rp0.2、Rm、A、Z、Ag、屈强比、均匀塑性区间、加工硬化率。
- 晶粒/晶界：15° HAGB 有效截距或 ECD、长宽比、长轴—AD 夹角、2°–5°与5°–15°边界绝对线密度。
- 位错：KAM/GROD/GOS（代理量）、织构修正 XRD 总位错密度和微应变、TEM/ECCI 位错形貌及类型。
- 织构/滑移：PF/ODF、织构指数、组分体积分数、给定载荷下 Schmid 因子、CRSS 归一化驱动力、VPSC/CPFEM 滑移份额。
- 模型：FE 的 PEEQ、应力三轴度、Lode 参数、表芯梯度及路径；强化预算预测误差和不确定度。

## Required controls

- 同炉批 O/N/H/C/Fe 实测；若研究“低氧效应”，增加不同氧水平对照。
- 统一 Rp0.2 算法；不同延性指标不混用。
- EBSD 至少覆盖独立棒材和表层—芯部位置。
- 模型预测与 TEM/XRD/滑移迹线独立验证，不用同一代理量同时建立并验证模型。

## Falsification checks

- HAGB 尺寸未降低：不成立经典细晶强化主导。
- XRD 总位错密度与屈服增量不随状态一致变化：不成立位错强化主导。
- CPFEM/VPSC 与 TEM 未共同支持 `<c+a>` 相对参与增加：不成立滑移机制转变。
- 强化项置信区间重叠或残差过大：只报告多机制协同与模型局限。
