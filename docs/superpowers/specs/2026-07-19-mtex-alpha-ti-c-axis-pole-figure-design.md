# MTEX 六方 α-Ti c 轴取向分布极图设计

## 1. 目标与范围

在 Windows 11 和 MATLAB R2025a 环境中安装 MTEX 6.1.1，并为本项目六组 Gr4B23271/TA4 商业纯钛 EBSD 数据建立可复现的 `{0001}` 极图分析流程。`{0001}` 极点用于表征六方 α-Ti 的 c 轴取向分布。

本阶段包括 MTEX 安装、环境验证和分析流程设计；不覆盖 KAM、GND、孪晶识别或滑移系分析。原始 CTF 文件保持只读，不覆盖现有 `_denoised.ctf` 或其他实验数据。

## 2. 运行环境与安装边界

- MATLAB：R2025a，安装目录为 `C:\Program Files\MATLAB\R2025a`。
- MTEX：采用包含 Windows 预编译二进制文件的官方 MTEX 6.1.1 发布包。
- MTEX 安装目录：`C:\Users\22069\Documents\MATLAB\mtex-6.1.1`。
- 项目仓库不提交 MTEX 本体，只保存项目级 MATLAB 分析脚本、配置、统计表和图件。
- MATLAB 未加入系统 PATH，因此自动化命令使用 `C:\Program Files\MATLAB\R2025a\bin\matlab.exe` 的绝对路径。
- 安装时不修改任何原始 EBSD 数据；除 MTEX 安装目录及 MATLAB 必要的用户级配置外，不写入项目外的其他位置。

## 3. 数据与坐标约定

输入数据为以下六组原始 CTF 文件：

- `d7`：TA4-M，冷变形量 0%；
- `d6_48`：TA4-Y-6.48，冷变形量 14.31%；
- `d6_02`：TA4-Y-6.02，冷变形量 26.04%；
- `d5_6`：TA4-Y-5.60，冷变形量 36.00%；
- `d5_25`：TA4-Y-5.25，冷变形量 43.75%；
- `d5`：TA4-Y-5.00，冷变形量 48.98%。

每幅图为 600 × 600 规则方形网格，步长 0.5 μm，扫描区域约 300 × 300 μm。坐标定义为：

- 扫描图水平方向 `X = AD`，即棒材轴向；
- 扫描图竖直方向 `Y = RD`，即纵截面内径向；
- `Z = ND`，即 EBSD 扫描面法向。

CTF 中欧拉角声明相对于 Sample Coordinate System `CS0`。正式计算前必须通过 IPF 图和 c 轴散点极图验证空间坐标与欧拉角参考系的转换选项，不能只根据图像外观假定方向正确。

## 4. 相选择与数据口径

正式极图采用原始 CTF 中所有已索引的 HCP `Ti-Hex` 像素进行面积加权。未索引点与少量 `Titanium cubic` 点不参与 ODF 或极图计算。

选择原始 CTF 作为主数据是为了避免 `_denoised.ctf` 对未索引区域的填充改变取向面积权重。去噪文件仅用于敏感性检查：比较原始数据与去噪数据的极图峰值位置、最大极密度和主要取向分布是否一致。若二者差异显著，正式结果继续保留原始数据，并报告差异而不直接用填充结果替代。

## 5. 计算方法

每组样品按以下顺序处理：

1. 使用 `EBSD.load` 导入 CTF，并显式处理空间坐标与欧拉角参考系。
2. 检查相名称、像素总数、索引率、扫描步长、坐标范围和 IPF 图方向。
3. 选择已索引 `Ti-Hex` 像素，不对纹理计算使用晶粒等权平均。
4. 使用全部 α-Ti 像素取向通过 `calcDensity` 计算面积加权 ODF。
5. 主分析采用半宽 5° 的统一核函数；另以 10° 半宽进行敏感性检查，避免结论依赖单一平滑参数。
6. 使用六方晶体方向 `[0001]` 绘制 `{0001}` 极图，采用上半球、等面积投影和 antipodal 表示。
7. 六组样品采用相同投影、相同核函数、相同等值线级别及统一 m.r.d. 色标。
8. 统计每组最大极密度、极密度峰值位置，以及 c 轴相对 AD 的夹角分布。

主结果为像素面积加权极图。晶粒平均取向等权极图仅作为补充诊断，不与面积加权结果混用。

## 6. 输出设计

项目后续分析文件放置于 `tools/mtex/`，派生结果放置于新目录 `results/mtex_c_axis_pf/`。输出包括：

- 六组 `{0001}` 极图的统一色标六联图；
- 每组独立的 `{0001}` 极图；
- 用于坐标检查的低密度 c 轴散点极图；
- CSV 汇总表：样品、冷变形量、有效 α-Ti 像素数、索引率、最大 m.r.d.、峰值方向及 c 轴—AD 夹角统计；
- 运行日志：MATLAB、MTEX 版本、输入文件、参考系转换选项、核半宽和输出时间；
- PNG 用于快速检查，PDF 或 SVG 用于论文排版。

图中横向明确标注 AD，纵向标注 RD。图注应说明投影方式、ODF 核半宽、是否使用 antipodal 以及极密度单位 m.r.d.。

## 7. 安装与环境验收

MTEX 安装完成后必须通过以下检查：

1. `mtex_version` 返回 6.1.1；
2. `which('EBSD')`、`which('calcDensity')` 和 `which('plotPDF')` 指向指定 MTEX 安装目录；
3. MTEX 启动过程无缺失 MEX 文件或路径冲突错误；
4. MATLAB 能导入 TA4-M 原始 CTF，并识别 600 × 600 网格、0.5 μm 步长和两个已定义相；
5. 能选出 `Ti-Hex` 像素并生成一张临时 `{0001}` 极图；
6. 临时输出关闭后，原始 CTF 的文件大小和哈希保持不变。

如果预编译 MEX 文件不能运行，先使用 MTEX 自带检查与下载机制；只有该机制失败时才考虑安装 MinGW 并重新编译。c 轴极图流程不依赖 Optimization Toolbox，但当前环境已安装该工具箱，可供后续 GND 分析使用。

## 8. 错误处理与质量控制

- 若 `EBSD.load` 提示参考系选项不明确，分别测试空间坐标转换和欧拉角转换方案，用现有 Channel 5 IPF/极图输出及 AD 方向进行判定。
- 若相名称导入后发生变化，按相 ID、晶格常数和六方对称性共同确认 α-Ti，相选择不能仅依赖字符串。
- 若某组原始索引率偏低，不采用全图无条件填充；同时报告有效像素数并进行原始/去噪敏感性对比。
- 若六组最大 m.r.d. 差异较大，先计算全部结果再确定统一色标上限，禁止逐图自动缩放后直接比较颜色。
- 若 5° 与 10° 半宽导致峰值位置或变形趋势发生实质改变，应报告参数敏感性，暂不形成确定性的织构演化结论。

## 9. 完成标准

环境层面以 MTEX 6.1.1 可由 MATLAB R2025a 无错误加载并完成 TA4-M CTF 导入及临时 `{0001}` 极图为完成。分析层面以六组数据均按同一坐标、相选择、ODF 参数和色标规则输出极图及统计表为完成。任何结果不得覆盖原始 CTF，且每张正式图均可由项目脚本重新生成。
