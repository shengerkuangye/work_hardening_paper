# C轴极图大图与平均取向折线图设计

## 1. 目标

基于现有六个冷变形状态的 EBSD 数据，分别生成 raw 和 denoised 的 `{0001}` c轴极图大图，并分别生成 c轴相对棒材轴向 AD 的平均取向折线图。图件用于论文主文或补充材料，保持 raw 与 denoised 的数据来源和证据属性分离。

## 2. 输出文件

输出目录为：

`results/mtex_ebsd_comprehensive/05_texture/`

新增四个文件：

1. `c_axis_pole_figures_raw.png`
2. `c_axis_pole_figures_denoised.png`
3. `c_axis_mean_orientation_raw.png`
4. `c_axis_mean_orientation_denoised.png`

不得覆盖现有 `pole_figures.png`、原始 CTF 或其他已注册结果。

## 3. c轴极图大图

### 3.1 数据与算法

- 相：`Ti-Hex`；
- 极点：α-Ti `{0001}`；
- 状态顺序：0%、14.31%、26.04%、36%、43.75%、48.98%；
- 每张大图采用 2×3 排列；
- raw 与 denoised 分别输出；
- 使用与现有综合纹理分析一致的像素加权 ODF；
- 核函数、半宽和网格分辨率沿用现有注册参数；
- 投影采用上半球、等面积投影和 antipodal 表示；
- 试样坐标保持 AD 水平，并保留必要的 AD/TD-RD 方向标识。

### 3.2 色标与标注

- raw 和 denoised 两张大图使用同一个全局 MRD 色标范围；
- 色标范围由全部 12 个状态的 `{0001}` 极密度共同确定，不分别自动缩放；
- 每个面板只标注冷变形量，避免文件名或处理流程文字遮挡极图；
- 图题分别明确 `raw` 和 `denoised`；
- 输出分辨率为 300 dpi，采用论文可读字号和紧凑留白。

## 4. 平均取向折线图

### 4.1 指标定义

使用像素加权的 c轴–AD 无向锐角：

`theta = acos(abs(c dot AD))`

raw 与 denoised 分别绘图。横坐标为冷变形量，纵坐标为 c轴–AD 夹角，单位为度。

### 4.2 图形编码

- 主折线表示六个状态的平均 c轴–AD 夹角；
- 圆点表示各状态平均值；
- 同图显示 P10–P90 范围，优先采用浅色误差带；若误差带影响可读性，则采用上下误差棒；
- raw 与 denoised 两张图使用相同的横坐标、纵坐标范围、颜色、线宽和标记尺寸；
- 每个平均值直接标注到小数点后两位；
- 图中明确 `AD horizontal` 或等价坐标说明；
- 不将 raw 和 denoised 画在同一张图中。

## 5. 数据流与实现边界

极图应由现有 MTEX 数据加载和 ODF 计算流程重新绘制，不从旧 PNG 裁剪。平均取向数据优先读取已验证的 `texture_summary.csv`；生成脚本需检查六个状态完整、状态键唯一、variant 正确且所有数值有限。

新增绘图逻辑应放在独立 MATLAB 函数或现有纹理生成器中的明确子函数内，并提供可单独运行的入口。不得修改原始数据，也不得把 denoised 作为独立实验重复。

## 6. 验证

自动验证应覆盖：

- 四个输出文件均存在且非空；
- raw 和 denoised 各恰有六个状态；
- 状态顺序和冷变形量正确；
- 两张极图采用相同 MRD 上限；
- 两张折线图采用相同坐标范围；
- 折线平均值与 `texture_summary.csv` 对应行一致；
- raw 与 denoised 不被交换；
- 现有 CTF 的 SHA-256、大小和时间戳不变。

视觉检查应确认：

- 2×3 面板无裁切、遮挡或过大留白；
- 极图方向标识和 AD 水平约定清晰；
- 色标、单位、状态标签和平均值标注可读；
- P10–P90 范围不遮挡平均值折线；
- 两种数据处理版本可直接并排比较。

## 7. 解释边界

平均 c轴–AD 夹角用于判断整体净取向变化，不排除织构组分重分配、展宽、收窄或局部旋转。raw 为主要定量结果，denoised 仅用于处理敏感性比较。极图和平均夹角均不能单独识别实际滑移、孪生或位错机制。
