# 2026-08-24 项目清理记录

## 判定原则

1. 原始实验数据和唯一来源文件必须保留。
2. 当前正文、可复现脚本、正式参考文献和正文直接引用图必须保留。
3. 内容完全相同的副本只保留语义清楚、位置正确的一份。
4. 缓存、锁文件、运行 PID、空日志、渲染页和临时依赖不作为研究产物保存。
5. 无法仅凭现有证据确认废止的分析结果继续保留，不按时间早晚臆断删除。
