## 先确认文章要回答的问题

当前研究问题：在 0–48.98% 名义截面减缩率范围内，高角度晶界所界定的晶粒尺度与晶内低角度亚结构如何演化，这些变化与 Grade 4 工业纯钛的旋锻强化及断后延性变化有何关系？

当前文章顺序保持为：研究意义与具体问题 → 材料和实验 → 拉伸性能 → 晶粒/晶界与亚结构 → ODF/Schmid → TEM 预留 → KAM-GND → 机制综合及贡献问题 → 结论。

可直接讨论的是已测性能、所测视场内的组织差异及其相关性。需要进一步验证的是具体位错组态、实际滑移活动以及不同组织因素的独立强化增量。位错贡献最大作为拟检验问题管理，不能成为筛选实验或模拟结果的前提。MD 保留为可选补充，尚未作为已完成方法加入正文。

## 本轮已经按什么顺序修改

1. 核对事实与指标定义，区分直接记录、旧稿继承信息、解释和待开展工作。
2. 修订方法、力学结果、组织与取向结果；保留已有有效统计数值，不重算实验、不制作新图。
3. 将旧强度口径图、旧硬化图和旧强化模型转入支持记录；正文图表连续编号。
4. 重写机制综合，修正 ECD、LAGB、KAM-GND、Schmid 的解释范围。
5. 重写引言、结论和摘要，收紧题名承诺；文献按正文实际首次出现顺序重新编号。
6. 检查图表路径、统计表转写、引用与章节对应，形成下面的人工审核模块。

本轮是完成可由现有资料支持的第一轮全文修改，不表示实验缺口已补齐，也不表示已经达到某一区期刊的录用条件。

先读上面的研究问题，再按 M01–M11 审核。这个顺序按依赖关系安排，不按摘要在最前面的排版顺序安排。每个模块都应留下“确认、修改、待补”及具体依据。

## 各轮审核具体怎么做

M01–M02 优先由掌握原始实验记录的人审核。先确认材料和加工状态，再确认机台通道、屈服提取及统计集合。当前表 2 是既定曲线口径的转写，审核通过需要原始数据和算法依据，不能只确认数值与上一稿一致。

M03–M06 由熟悉取样和 EBSD/TEM 的人员审核。先检查空间坐标、样品位置及分割/邻域设置，再解释组织差异。KAM-GND 的有效像素比例随状态变化，应评估这一选择如何影响比较；不能以很多像素或晶粒代替独立试样重复。

M07–M08 由主要作者与机制分析人员共同审核。对每个因果句，写出支持它的本研究结果和所需假设。若无法独立约束取向或总位错密度，贡献讨论可以保持相关性与敏感性层级，不强行拼接三项百分比。

M09 可以与前几轮并行开展，但研究贡献的最终措辞应在 M07–M08 后确定。现有文献已讨论纯钛旋锻中的晶界、位错和织构作用，因此要比较初态、应变范围、实际组织及方法分辨能力。参考文献数量不作为质量指标，最终仍需扩展与具体问题直接相关的原始研究和相反证据。

M10–M11 最后进行。当前中文稿用于审查科学内容，英文稿、目标期刊摘要长度、Highlights 等在科学内容稳定且期刊确定后落实。分区是期刊分类结果，不是一套自动保证论文质量的格式；按[官方分区平台](https://www.fenqubiao.com/)核对适用年度及大类/小类口径，本轮没有认定某一本候选期刊属于目标分区。

## 篇幅与逐图解释的取舍

本轮按中文正文汉字统计，排除图注、表格、占位说明和参考文献后，Results 约 3960 字，Discussion 约 2580 字。该计数仅用于本稿内部比较，不能换算为目标期刊的英文词数要求。现在结果部分已具备空间特征、定量分布和状态差异的解释，继续修改应优先提高每段的信息作用。

Results 的每组图按“观察到的特征—关键统计对比—该组结果支持的认识”组织；Discussion 再解释原因、与已有研究比较并交代解释范围。KAM 与 GND 使用同源数据，应减少重复罗列分箱；ODF 优先明确组分及方向含义，再决定保留多少欧拉角数值。TEM 取得结果后据实际信息量调整 3.4，篇幅不预先平均分给每张图。

## 建议的人工修改记录格式

每次集中处理一个模块，使用以下格式即可：

```text
模块：M01
状态：确认 / 修改 / 待补
对应章节、表格或图：
原始依据（实验记录、原始文件、论文页码等）：
需要替换或补充的内容：
对其他模块的影响：
```

“确认写法流畅”与“确认实验事实”应分开。第一轮人工建议直接从 M01 开始，重点补齐材料初态、旋锻与热处理记录、拉伸条件和取样坐标；这些内容会决定后续结果能解释到什么程度。
