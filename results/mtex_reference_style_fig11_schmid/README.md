# Fig. 11参考形式：滑移族施密特因子图

## 图件结构

- 六个直径分别生成独立四联图：(a-c)基面`<a>`、柱面`<a>`和锥面`<c+a>`施密特因子空间图；(d)三类晶粒面积加权分布。
- 另保留7d-5d八联对比图：(a-c)7d三类空间图；(d-f)5d三类空间图；(g-h)两种状态的面积加权分布。
- 空间图采用0-0.5统一色标，不绘制等高线；灰色细线表示重构晶界，灰色背景对应未索引或非Ti-Hex区域。

## 计算定义

- 输入：去噪CTF。
- 载荷：AD方向单轴拉伸，`vector3d.X`。
- 晶粒重构阈值：2°。空间图包含全部重构Ti-Hex晶粒；分布统计仅保留像素数不少于5的重构Ti-Hex晶粒。
- 每个晶粒采用平均取向。
- 每个滑移族取全部对称变体中绝对施密特因子的最大值。
- 同一晶粒的滑移族值赋给该晶粒的全部像素，用于绘制空间图。
- 分布以筛选后重构晶粒的面积加权，组距为0.02；未按施密特因子阈值删除晶粒。

## 六个直径的主要数值

| 状态 | 基面`<a>`面积均值 | 柱面`<a>`面积均值 | 锥面`<c+a>`面积均值 |
|---|---:|---:|---:|
| 7d | 0.1661 | 0.4519 | 0.4637 |
| 6.48d | 0.1584 | 0.4544 | 0.4672 |
| 6.02d | 0.1575 | 0.4556 | 0.4664 |
| 5.6d | 0.1657 | 0.4509 | 0.4698 |
| 5.25d | 0.1596 | 0.4508 | 0.4703 |
| 5d | 0.1709 | 0.4484 | 0.4712 |

采用项目既定Grade 4纯钛CRSS（基面252 MPa、柱面154 MPa、锥面`<c+a>` 756 MPa）后，以柱面平均驱动力为1进行归一化：

| 状态 | 基面`<a>` | 柱面`<a>` | 锥面`<c+a>` |
|---|---:|---:|---:|
| 7d | 0.2246 | 1.0000 | 0.2090 |
| 5d | 0.2330 | 1.0000 | 0.2140 |

锥面`<c+a>`和基面`<a>`的几何有利程度略有增强，但考虑固定CRSS后，柱面`<a>`仍保持明显的名义启动优势。本图只能表示AD载荷下的几何倾向及固定CRSS筛选结果，不能单独证明实际滑移系已经启动。

## 建议图注

单一直径版本：

Gr4B23271商业纯钛在直径为X mm时的滑移族施密特因子图及分布：（a）基面`<a>`；（b）柱面`<a>`；（c）一阶锥面`<c+a>`；（d）晶粒面积加权施密特因子分布。施密特因子按AD方向单轴拉伸计算，每个晶粒取对应滑移族全部对称变体中的最大绝对值。

7d-5d对比版本：

不同冷变形状态下Gr4B23271商业纯钛的滑移族施密特因子图及分布：（a-c）7d样品；（d-f）5d样品；（a，d）基面`<a>`；（b，e）柱面`<a>`；（c，f）一阶锥面`<c+a>`；（g，h）分别为7d和5d样品的晶粒面积加权施密特因子分布。施密特因子按AD方向单轴拉伸计算，每个晶粒取对应滑移族全部对称变体中的最大绝对值。
