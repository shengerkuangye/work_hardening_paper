## 已确认的采集参数

依据全部 105 个 TIFF 的 FEI XML 标签 34683：

- 仪器型号：Talos F200X；加速电压：200000 V（200 kV）。
- `AcquisitionStartDatetime` 均为 2026-09-23（UTC）。部分 STEM 的 `AcquisitionDatetime` 为 1970 年占位值，未用其确定实验日期。
- STEM 导出图为 2048×2048，Camera 导出图为 4096×4096；TIFF 均为 RGB 显示导出，不能把显示灰度作为原始定量强度。
- STEM 文件名倍率为 22500×、32000×、45000×。对应元数据像素尺寸分别为 2.17037、1.52187、1.07612 nm，整帧宽度分别为 4.44492、3.11678、2.20390 μm。
- 8 个电子衍射 TIFF 的倒易空间像素标定为 0.0113926 nm⁻¹/px；文件名为 520 mm，元数据相机长度为 0.524 m。后续标定需保留该差别。
- `DF-O` 文件的 XML `BinaryResult/Detector` 均为 `DF-S`。本次保留文件名标签，不擅自解释 DF-O 的独立探测器身份或几何范围。对 0006 和 0023 的 MRC 只读抽查显示 DF-S 与 DF-O 数组不相同，不能直接判为重复副本。

本次解析了 TIFF 元数据与全部 MRC 的尺寸/模式头；未解析 EMD 的完整层级，也未完成各格式像素等价性校验。

## 初步观察及适用范围

已浏览两组 BF-S、DF-S、HAADF 全部缩略图及全部 8 张带标注衍射图。两组实空间图像均存在大量弯曲、交织的线状衬度，并与宽带状明暗变化及相对均匀区域共存。0011（7MM）和 0028（5MM）的 BF-S/DF-S 图具有较清楚的线状特征，可用于后续位错衬度核查。两组均有这些特征，不应先把 7MM 组描述为“无位错”或“完全退火组织”。

衍射图 0001、0018 可见二维排列的多个斑点，其他图中可见少数较亮的近共线斑点。未对晶带轴、g 矢量、晶面间距或两束条件作最终认定。原始 PNG 中的“6-8”等数字是图像编号，不能作为晶体学标定。

这些观察支持开展局部缺陷衬度和组织不均匀性分析；本轮不据图像深浅或可见线条多少计算位错密度、不识别 Burgers 矢量及实际滑移系、不判定孪晶或将宽条带直接命名为晶界/位错墙，也不据局部图像排列强化贡献大小。两组薄膜厚度、倾转和衍射条件尚未匹配。

## 产物与复现

- `file_manifest.csv`：全部原始文件及 MRC 头信息。

- `tem_source_group_comparison_draft.png`：供图 10 选图审阅的六面板草图；上排 M-7.00，下排 Y-5.00，均为纵截面，每排 BF-S、DF-S、来源对应衍射图。对应原图和选择理由见 `comparison_panels.csv`。该图只为展示可辨认的局部线状衬度，不据此声称两组位错密度有显著差异。

预览仅对完整导出图等比例缩放并在图外添加标签，保留原比例尺，无裁剪、反相、增强、去噪或生成式处理。新增拼图不作为定量强度数据。

复现命令：`python3 tools/inventory_tem_9df.py`。依赖 Pillow；输入目录只读，输出限定在本目录。
