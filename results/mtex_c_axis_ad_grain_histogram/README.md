# c轴—AD夹角晶粒面积加权分布

本目录以与晶粒尺寸分布图相近的六行纵向版式，给出六种冷变形状态中Ti-Hex重构晶粒平均c轴与AD之间锐角的柱状分布。raw CTF为主结果，denoised CTF以黑色虚线表示敏感性结果。

## 计算口径

- 晶粒重构：2°取向差阈值，最小晶粒像素数5；该口径与滑移倾向计算一致。
- 晶粒取向：每个保留Ti-Hex晶粒的平均取向。
- 角度：c轴 `[0001]` 与AD `vector3d.X` 的反极性锐角，范围0°–90°。
- 分箱：0°–90°，宽度2°。
- 权重：重构晶粒面积；每个状态的柱状频率之和为100%。
- 图中紫色区域为前一步参考文献CRSS计算得到的 `<c+a>` 可能优先取向包络，即0°–10.6°。

## 结果解释

六种状态的分布均主要集中在约60°–90°，面积加权均值为78.86°–79.88°，中位数为79.23°–81.09°。这表明当前EBSD视场中多数晶粒的c轴趋向垂直而不是平行AD。不同冷变形量之间的均值变化不足约1.1°，且呈非单调变化，不能据此认为冷变形使c轴持续向AD转动。

所有raw及denoised状态在0°–10.6°范围内的保留晶粒数量和面积均为0，与参考文献CRSS归一化后未识别出 `<c+a>` 优先晶粒的结果一致。该图描述的是变形后晶粒平均取向分布，不代表局部像素取向，也不能单独证明某一滑移系已经发生。

raw与denoised曲线基本重合：面积加权均值最大差值为0.037°，中位数最大差值为0.084°，单个2°分箱的面积频率最大差值为0.415个百分点，说明当前角度分布对去噪处理不敏感。每种状态只有一个EBSD视场，状态差异不能作为重复试验不确定度，也不能外推为整根棒材不存在其他取向晶粒。
