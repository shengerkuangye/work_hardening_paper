# Schmid 因子多统计口径敏感性分析

## 分析定义

- 载荷方向：轴向拉伸方向 AD（`vector3d.X`）。
- 晶粒取向：重构后、满足最小像素数要求的 Ti-Hex 晶粒平均取向。
- 滑移系：柱面 `<a>`、基面 `<a>` 和锥面 `<c+a>`；每个晶粒取同一滑移族所有对称变体中绝对施密特因子的最大值。
- 主结果采用晶粒面积加权；晶粒数量加权、原始 CTF 与去噪 CTF 用作敏感性检验。
- CRSS：柱面 `<a>` 154 MPa、基面 `<a>` 252 MPa、锥面 `<c+a>` 756 MPa，沿用项目既有分析采用的 Xiong et al., *Acta Materialia* 199 (2020) 561–577, Table 4 数值。
- CRSS 竞争比定义为

  `R_ca = (m_ca / 756) / max(m_prismatic / 154, m_basal / 252)`。

  `R_ca = 1` 表示仅按均匀轴向应力和固定 CRSS 判断时，锥面 `<c+a>` 与最有利 `<a>` 系具有相同名义启动应力。

## 7d 至 5d 的主要对比（去噪数据）

| 统计口径 | 柱面 `<a>`：7d → 5d | 变化 | 锥面 `<c+a>`：7d → 5d | 变化 |
|---|---:|---:|---:|---:|
| 数量加权均值 | 0.44897 → 0.45016 | +0.266% | 0.46406 → 0.47039 | +1.364% |
| 面积加权均值 | 0.45195 → 0.44841 | −0.783% | 0.46366 → 0.47117 | +1.620% |
| 数量中位数 | 0.45708 → 0.45295 | −0.903% | 0.46809 → 0.47619 | +1.730% |
| 面积加权中位数 | 0.45931 → 0.44981 | −2.067% | 0.46721 → 0.47696 | +2.086% |
| 面积加权 90 分位数 | 0.49262 → 0.48610 | −1.323% | 0.49450 → 0.49589 | +0.282% |
| 面积加权 95 分位数 | 0.49609 → 0.49198 | −0.828% | 0.49713 → 0.49807 | +0.189% |
| 面积加权 5%–95% 截尾均值 | 0.45613 → 0.44985 | −1.377% | 0.46548 → 0.47256 | +1.522% |

柱面 `<a>` 的数量加权均值略有上升，而面积加权均值、中位数、截尾均值和高分位数均下降。这表明变化与晶粒面积分布有关，单一数量均值会掩盖较大晶粒所代表的取向变化。锥面 `<c+a>` 的均值和中位数在各种口径下均上升，方向较为稳定。

## 固定阈值敏感性（去噪数据，晶粒面积比例）

| 条件 | 柱面 `<a>`：7d → 5d | 变化/百分点 | 锥面 `<c+a>`：7d → 5d | 变化/百分点 |
|---|---:|---:|---:|---:|
| `m >= 0.40` | 91.07% → 94.43% | +3.35 | 98.08% → 99.73% | +1.65 |
| `m >= 0.44` | 71.54% → 63.19% | −8.35 | 82.78% → 88.07% | +5.29 |
| `m >= 0.46` | 49.45% → 36.47% | −12.98 | 58.96% → 71.29% | +12.33 |
| `m >= 0.48` | 25.63% → 14.86% | −10.77 | 31.87% → 46.19% | +14.31 |

柱面 `<a>` 的阈值曲线在约 `m = 0.42` 附近发生交叉：中高区间的面积比例略增，但极高值尾部明显减少。因而不能笼统表述为“所有柱面施密特因子均下降”，更准确的表述是柱面分布由极高值区向中高值区重新分配。锥面 `<c+a>` 在 `m >= 0.44–0.48` 的高值尾部均增加。

阈值以上晶粒的条件均值变化远小于面积比例变化。例如，在 `m >= 0.46` 时，柱面条件均值仅由 0.48074 降至 0.47780，而高值面积比例下降 12.98 个百分点；锥面条件均值由 0.48132 升至 0.48328，而高值面积比例增加 12.33 个百分点。可见更显著的信号来自“高值晶粒占比”，而不是对入选晶粒再次求均值。

## CRSS 归一化竞争

| 指标（去噪） | 7d | 5d | 变化 |
|---|---:|---:|---:|
| `R_ca` 面积加权均值 | 0.21011 | 0.21496 | +2.31% |
| `R_ca` 面积加权中位数 | 0.20855 | 0.21585 | +3.50% |
| `R_ca` 面积加权 90 分位数 | 0.23252 | 0.23699 | +1.92% |
| 面积比例 `R_ca >= 0.20` | 65.33% | 77.63% | +12.30 个百分点 |
| 面积比例 `R_ca >= 0.25` | 2.38% | 2.05% | −0.32 个百分点 |
| 面积比例 `R_ca >= 0.50` | 0% | 0% | 0 |
| 面积比例 `R_ca >= 1.00` | 0% | 0% | 0 |

采用上述固定 CRSS 后，锥面 `<c+a>` 相对最有利 `<a>` 系的几何竞争性小幅增强，但所有晶粒仍低于 `R_ca = 0.5`，更没有达到 `R_ca = 1`。按这一简化模型，六个状态中没有晶粒由锥面 `<c+a>` 成为名义最优先滑移族；7d 和 5d 的柱面 `<a>` 优先面积比例分别为 99.253% 和 99.945%。

因此，本结果能够支持“随变形增加，取向分布使锥面 `<c+a>` 的几何有利程度相对增强，同时柱面 `<a>` 极高因子晶粒比例减少”，但不能单独支持“锥面 `<c+a>` 已实际启动”。实际启动仍需局部应力、多滑移相容性、潜在硬化后的有效 CRSS、滑移迹线或 Burgers 矢量等证据。

## 统计使用建议

1. 正文主统计采用面积加权中位数或面积加权均值，并同时报告 `m >= 0.46` 的面积比例；前者描述总体位置，后者描述高值尾部。
2. 将 `0.40–0.48` 的完整阈值扫描作为敏感性检验，不应只挑选变化最大的阈值。
3. 不建议删除低于或高于某个阈值的晶粒后重新计算全体均值。阈值筛选应保留全部晶粒作为分母，报告“达到阈值的晶粒数量/面积比例”。
4. 原始与去噪结果在变化方向和幅度上接近，说明上述主要趋势对 EBSD 去噪处理不敏感。

## 文件说明

- `schmid_statistical_summary.csv`：均值、中位数、分位数、截尾均值和名义启动应力分位数。
- `schmid_threshold_sensitivity.csv`：施密特因子固定阈值扫描及阈值以上的条件均值。
- `crss_competition_ratio_summary.csv`：CRSS 归一化竞争比的位置和分位数统计。
- `crss_competition_threshold_sensitivity.csv`：竞争比阈值扫描。
- `crss_preferred_family_summary.csv`：固定 CRSS 下名义最优先滑移族的数量和面积比例。
- `initial_final_method_comparison.csv`：7d 与 5d 在所有统计口径下的直接对比。
- `key_method_prismatic_pyramidal_comparison.csv`：正文关键统计方法的柱面 `<a>`—锥面 `<c+a>` 精简对照表。
- `schmid_statistical_sensitivity_parameters.csv`：分析参数、CRSS 来源和解释边界。
- `schmid_statistical_sensitivity_6state.png/.tif`：六状态多指标比较图。
- `schmid_initial_final_ccdf.png/.tif`：7d/5d 阈值互补分布图。
- `key_method_prismatic_pyramidal_comparison.png/.tif`：关键统计量相对变化和高值面积比例变化的分组柱状图。
